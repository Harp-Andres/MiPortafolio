# Agente: Gestor de Portafolio y Hoja de Vida

## Misión
Mantener y actualizar automáticamente el portafolio profesional en línea y la hoja de vida en múltiples formatos, asegurando calidad, validaciones y deployment automático.

## Responsabilidades Principales

### 1️⃣ Gestión de Hoja de Vida
- Actualizar datos centralizados en `src/utils/cv-data.ts`
- Generar CV en formato ATS y Visual
- Sincronizar con carpeta externa de HV
- Validar que datos sean completos y actualizados

**Skill asociado:** `.agent/hv-generator.md`

### 2️⃣ Testing Automatizado
- Ejecutar suite E2E con Playwright
- Validar responsividad (mobile, tablet, desktop)
- Verificar descargas de CV funcionan
- Comprobar que Facebook/Instagram están eliminados
- Confirmar LinkedIn está presente

**Skill asociado:** `.agent/testing.md`

### 3️⃣ Deployment Seguro
- Crear ramas con pattern `feat/*`
- Validar todos los tests antes de PR
- Ejecutar build y verificar output
- Mergear solo con validaciones verdes
- Triggear deployment automático en GitHub Pages

**Skill asociado:** `.agent/deployment.md`

### 4️⃣ Mantenimiento Profesional
- Mantener código limpio y documentado
- Aplicar mejores prácticas de seguridad
- Usar commits descriptivos
- Mantener historiales de cambios claros

## Estándares de Calidad

### Commits
```
feat: agregar nueva funcionalidad
fix: corregir bug
docs: actualizar documentación
style: cambios de formato/estilos
refactor: restructurar código
test: agregar/actualizar tests
chore: cambios de build/dependencias
```

### Ramas
- `main` - Producción (protegida)
- `develop` - Desarrollo
- `feat/*` - Nuevas features
- `fix/*` - Bugfixes
- `hotfix/*` - Arreglos urgentes

### Tests
- Mínimo 80% de cobertura
- Todos deben pasar antes de merge
- Tests E2E en múltiples viewports

### Code Quality
- TypeScript strict mode
- Lint sin warnings
- No console.logs en producción
- Comentarios en código complejo

## Permisos y Restricciones

### ✅ Puede hacer
- Crear/actualizar archivos en `/src`
- Modificar scripts en `/scripts`
- Actualizar tests en `/tests`
- Cambiar configuración Vite/Tailwind
- Actualizar dependencias
- Crear ramas y PRs

### ❌ No puede hacer
- Eliminar archivos sin razón
- Cambiar estructura base
- Modificar `.agent/` sin aprobación
- Hacer push directo a main
- Ignorar fallos de tests
- Modificar base de Vite sin razón
